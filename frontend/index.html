Provenance, Splits & Preprocessing Dossiers

Datasets.

DATASET 01

Fakeddit

Provenance: Reddit multimodal fake-news corpus (image + headline/title pairs).
Modalities: Image (RGB) + Text.
Implemented Configs: 4 Text Encoders, 4 Visual Encoders, Concatenation Fusion & Weighted Late Fusion.
Split Counts: Populated from GET /api/datasets.

PREPROCESSING & LEAKAGE CONTROL:
  • HTML & Unicode normalization
  • URL standardization
  • Text normalization preserving meaningful casing, negation & hashtags
  • RGB image validation
  • Perceptual hashing (dHash) deduplication
  • Grouped splitting to prevent image-reuse leakage
DATASET 02

FaceForensics++

Provenance: Large-scale facial manipulation forensic video benchmark.
Modalities: Video-Only (MP4 frames — no text-video fusion).
Implemented Experiments: Xception, EfficientNet-B4, ResNet-50 (Frame), OrderedLSTM (Temporal), Two-Model Frame Ensemble.
Categories: Original, Deepfakes, Face2Face, FaceSwap, NeuralTextures.

PREPROCESSING & LEAKAGE CONTROL:
  • Source-video-level grouping (zero identity/source leakage across splits)
  • Uniform temporal frame sampling
  • Facial region detection & cropping
  • Blending-seam margin preservation around face boundaries
  • Standardized frame resizing & normalization
DATASET 03

SNLI-VE + Mismatch

Provenance: Stanford Natural Language Inference Visual Entailment + Custom Mismatch Suite.
Modalities: Premise Image + Hypothesis Text.
Implemented Configs: Frozen CLIP Feature Extractor + supervised clip_concat & clip_interactions fusion heads (+ non-trained mismatch heuristic).
NLI Mapping: Entailment → REAL, Contradiction → FAKE, Neutral → UNCERTAIN.

PREPROCESSING & EVALUATION:
  • Strict image-disjoint train / val / test splitting
  • Text preprocessing & CLIP tokenization
  • Premise-image & hypothesis pairing
  • 3-class visual entailment with separate NLI vs. user-facing fields
  • Post-hoc mismatch heuristic categories: match, unrelated_caption, manipulated_matching, manipulated_misleading
